# Dogear
Dogear is a gamified reading tracker that verifies you have actually read the material rather than skimming through it.

## About the Project
Dogear was built by The High Bears team for the High School Innovation Challenge by the Romanian-American University in Bucharest.

## Our main goals are:
  - Fighting illiteracy by making reading more engaging and quizzing you on what you read
  - Adding competitive elements to solo reading
  - Helping friends track and compare reading habits

## Key Features
  - Reading Verification: Quizzes and checkpoints to test comprehension.
  - Progress Tracking: XP and achievements for reading consistency.
  - Social Competition: Reading streaks and friend leaderboards.
  - Shared Library: A crowdsourced catalogue of books.

## Disclaimer
This is a proof-of-concept demo built for the High School Innovation Challenge, not a finished product. Expect bugs and incomplete features.
